PFO 2 - Sistema de Gestión de Tareas con API y Base de Datos

Práctica Formativa Obligatoria 2 de Programación sobre Redes (IFTS29, 2° cuatrimestre 2026).

Endpoints de la API

MétodoRutaDescripción
POST/registroRegistra usuarios con contraseña hasheada
POST/loginVerifica credenciales y permite el acceso
GET/tareasAcceso a tareas (HTML de bienvenida)

Código fuente

Servidor Flask + SQLite y cliente de consola en hleopary/pfo2-api-tareas.

Ejecución local

python3 servidor.py   # inicia la API en http://127.0.0.1:5000
python3 cliente.py    # cliente de consola

Respuestas conceptuales (extracto)

  • ¿Por qué hashear contraseñas? Para no exponerlas en texto plano ante una filtración; el hash es irreversible, con sal por usuario y costoso de revertir.
  • ¿Ventajas de SQLite? Base embebida (un archivo), sin servidor/configuración, módulo sqlite3 estándar de Python, transacciones ACID y portabilidad.
